# ベンチマーク結果: CoreS3（2026-11-08）

- 機体: M5Stack CoreS3（ESP32-S3 rev v0.2、フラッシュ 16MB）、ILI9342C 320×240、SPI 40MHz
- 条件は [AtomS3 の結果](2026-11-08-atoms3.md) と同じ（kumiki は FIFO 経路と EXECUTE 一括を有効にした版）
- 理論上限: 320×240×16bit / 40MHz = 30.72ms（32.55fps）

| ID | 内容 | M5GFX 0.2.19 | kumiki | M5GFX 比 | 理論上限比（kumiki） |
|---|---|---|---|---|---|
| B1 | 全画面の塗りつぶし | 31.55 fps | 32.43 fps | **103%** | 99.6% |
| B2 | 全画面の転送（RGB565、無変換） | 32.53 fps | 32.45 fps | **99.8%** | 99.7% |
| B3 | RGB888 → RGB565 変換付き転送 | 32.20 fps | 32.16 fps | **99.9%** | 98.8% |
| B5 | 透過付きスプライト 32×32 ×64 | 32.59 fps | 24.99 fps | 77% | – |
| B8 | 円 20 個 + 文字列 | 289.1 fps | 139.4 fps | 48% | – |

## 所見

- M1 / M2 の性能条件「全画面の DMA 転送で M5GFX の 80% 以上」は、CoreS3 でも満たした（B2: 99.8%）。
- 小さな描画の固定費は、AtomS3 と同じ傾向（B5: 77%、B8: 48%）。改善候補は AtomS3 の結果ファイルに記載した。
- CoreS3 の電源投入（AXP2101 と AW9523 のレジスタ設定、AW9523 の P1_5 による LCD リセット）は、ベンチマークのファームウェア内に手書きしている。M2 でボード定義に移す。
