# kumiki

no_std Rust 向けの高速グラフィックドライバと、Device Tree ベースのハードウェア記述層・ボード定義。
最初の対象は ESP32-S3 / ESP32-P4 と M5Stack 製品（CoreS3、AtomS3、Tab5）。
